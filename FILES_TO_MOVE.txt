الملفات والمجلدات التي تنقلها إلى الجهاز الآخر

المسار الأساسي:
C:\Users\START\Desktop\اخر تعديل علي البرنامج CRM  ففقط\البرنامج

الحد الأدنى المطلوب:
- server
- client
- README.md

ملفات إعداد مهمة:
- server\.env
- server\prisma
- server\.whatsapp-runtime.json

لو تريد نقل النسخ الاحتياطية أيضًا:
- server\backups

لو تريد محاولة نقل جلسة واتساب الحالية:
- server\.wwebjs_auth
ملاحظة:
قد يطلب واتساب إعادة ربط حتى بعد نقل هذا المجلد.

لا يلزم نقل هذه المجلدات:
- server\node_modules
- client\node_modules
- client\.next
- server\logs

مهم جدًا:
لو بيانات العملاء موجودة في PostgreSQL على الجهاز القديم، لازم تنقل قاعدة البيانات أيضًا أو تعمل لها Export.
نقل ملفات المشروع وحدها لا ينقل البيانات المخزنة داخل قاعدة البيانات.

أفضل طريقة عملية:
1. انسخ المجلدات والملفات المطلوبة بالأعلى.
2. على الجهاز الجديد افتح terminal داخل server وشغل:
npm install
3. ثم افتح terminal داخل client وشغل:
npm install
4. تأكد من إعداد server\.env وقاعدة البيانات.

لو تريد تشغيل النظام بدون واتساب في الجهاز الجديد:
اترك الملف:
server\.whatsapp-runtime.json
كما هو إذا كانت القيمة:
{
  "enabled": false
}
